
# Credit Card Financial Dashboard

A Power BI dashboard for analyzing credit card transactions, revenue, customer demographics, and financial performance using PostgreSQL, SQL, and DAX.

## 📌 Project Overview

This project analyzes credit card transaction and customer data to identify revenue trends, transaction patterns, customer segments, and overall financial performance.

The dashboard converts raw data into interactive visual reports that make it easier to understand business performance and customer behaviour.

## 🎯 Objective

To build an interactive financial dashboard that helps analyze:

- Revenue and transaction performance
- Customer demographics
- Spending patterns
- Card category performance
- Weekly and quarterly trends
- Customer segmentation
- Financial KPIs

## 🛠️ Tools & Technologies

- *Power BI* – Data visualization and dashboard creation
- *PostgreSQL* – Database management
- *SQL* – Data querying and analysis
- *DAX* – Calculated columns and measures
